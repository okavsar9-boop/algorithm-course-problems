Given a string s, return whether its letters form a palindrome ignoring punctuation, spaces, and casing.

Example 1:
Input: s = "Bob wondered, 'Now, Bob?'"
Output: true
Explanation: Considering only letters and ignoring case, we get
"bobwonderednowbob" which is a palindrome.

Example 2:
Input: s = "race a car"
Output: false
Explanation: Considering only letters and ignoring case, we get "raceacar"
which is not a palindrome.
Constraints:

0 ≤ s.length ≤ 10^6
s consists of printable ASCII characters
See Solution
Problem 27.4 - Palindromic Sentence: Solution
Python
We can use the 'inward pointers' movement pattern, as usual for palindrome problems.

We compare characters starting from both ends of the string with two pointers, l and r, while skipping over non-letter characters.

At each iteration, we make progress towards the meeting point of the two pointers. We consider the following cases:

If the left character is not a letter, skip it
If the right character is not a letter, skip it
If both are letters, compare them (ignoring case)
If they don't match, return False
If they match, move both pointers inward
The string is palindromic if we never find a mismatch between letters.

Here's the implementation:

def palindromic_sentence(s):
  l, r = 0, len(s) - 1
  while l < r:
    if not s[l].isalpha():
      l += 1
    elif not s[r].isalpha():
      r -= 1
    else:
      if s[l].lower() != s[r].lower():
        return False
      l += 1
      r -= 1
  return True
Time & Space Analysis
n: the length of the string

Time: O(n) - at each iteration, we make progress towards the meeting point of the two pointers. after at most n iterations, the two pointers will meet

Extra space: O(1) - only using constant extra space for the two pointers

class PalindromicSentence {
public boolean solve(String s) {
int l = 0, r = s.length() - 1;
while (l < r) {
if (!Character.isLetter(s.charAt(l))) {
l++;
} else if (!Character.isLetter(s.charAt(r))) {
r--;
} else {
if (Character.toLowerCase(s.charAt(l)) != Character
.toLowerCase(s.charAt(r))) {
return false;
}
l++;
r--;
}
}
return true;
}
}
