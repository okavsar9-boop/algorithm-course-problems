Given two sorted arrays of integers, arr1 and arr2, return a new array that contains all the elements in arr1 and arr2 in sorted order, including duplicates.


Example 1:
Input:
arr1 = [1, 3, 4, 5]
arr2 = [2, 4, 4]
Output: [1, 2, 3, 4, 4, 4, 5]
Explanation: All elements are merged in sorted order.

Example 2:
Input:
arr1 = [-1]
arr2 = []
Output: [-1]
Explanation: When one array is empty, the result is just the other array.

Example 3:
Input:
arr1 = [1, 3, 5]
arr2 = [2, 4, 6]
Output: [1, 2, 3, 4, 5, 6]
Constraints:

arr1 and arr2 are sorted in ascending order
0 ≤ arr1.length, arr2.length ≤ 10^6
-10^9 ≤ arr1[i], arr2[i] ≤ 10^9

Problem 27.6 - Merge Two Sorted Arrays: Solution
Python
We can use the 'parallel pointers' movement pattern.

The key is that since both input arrays are sorted, we can build the merged array by always choosing the smaller of the current elements.

However, when a pointer reaches the end, we are not done. We still need to continue with the other pointer until the end of its array. Some candidates forget about this wrap-up work.

Here's the implementation:

def merge(arr1, arr2):
  p1, p2 = 0, 0
  res = []
  while p1 < len(arr1) and p2 < len(arr2):
    if arr1[p1] < arr2[p2]:
      res.append(arr1[p1])
      p1 += 1
    else:
      res.append(arr2[p2])
      p2 += 1
  while p1 < len(arr1):
    res.append(arr1[p1])
    p1 += 1
  while p2 < len(arr2):
    res.append(arr2[p2])
    p2 += 1
  return res
Time & Space Analysis
n1: the length of arr1

n2: the length of arr2

Time: O(n1 + n2) - each element from both arrays is visited exactly once during the merge process

Extra space: O(n1 + n2) - for the merged result array

function merge(arr1, arr2) {
  let p1 = 0,
    p2 = 0;
  const res = [];
  while (p1 < arr1.length && p2 < arr2.length) {
    if (arr1[p1] < arr2[p2]) {
      res.push(arr1[p1]);
      p1++;
    } else {
      res.push(arr2[p2]);
      p2++;
    }
  }
  while (p1 < arr1.length) {
    res.push(arr1[p1]);
    p1++;
  }
  while (p2 < arr2.length) {
    res.push(arr2[p2]);
    p2++;
  }
  return res;
}

class Merge {
  public List<Integer> solve(List<Integer> arr1, List<Integer> arr2) {
    int p1 = 0, p2 = 0;
    List<Integer> res = new ArrayList<>();
    while (p1 < arr1.size() && p2 < arr2.size()) {
      if (arr1.get(p1) < arr2.get(p2)) {
        res.add(arr1.get(p1));
        p1++;
      } else {
        res.add(arr2.get(p2));
        p2++;
      }
    }
    while (p1 < arr1.size()) {
      res.add(arr1.get(p1));
      p1++;
    }
    while (p2 < arr2.size()) {
      res.add(arr2.get(p2));
      p2++;
    }
    return res;
  }
}

class RunTests {
  public void runTests() {
    Object[][] tests = {
        // Example 1 from the book
        { new int[] { 1, 3, 4, 5 }, new int[] { 2, 4, 4 },
            new int[] { 1, 2, 3, 4, 4, 4, 5 } },
        // Example 2 from the book
        { new int[] { -1 }, new int[] {}, new int[] { -1 } },
        // Additional test cases
        { new int[] {}, new int[] {}, new int[] {} },
        { new int[] { 1 }, new int[] {}, new int[] { 1 } },
        { new int[] {}, new int[] { 1 }, new int[] { 1 } },
        { new int[] { 1, 3, 5 }, new int[] { 2, 4, 6 },
            new int[] { 1, 2, 3, 4, 5, 6 } },
        { new int[] { 1, 1, 1 }, new int[] { 1, 1, 1 },
            new int[] { 1, 1, 1, 1, 1, 1 } },
    };

    Merge solution = new Merge();
    for (Object[] test : tests) {
      int[] arr1Array = (int[]) test[0];
      int[] arr2Array = (int[]) test[1];
      int[] wantArray = (int[]) test[2];
      
      List<Integer> arr1 = new ArrayList<>();
      List<Integer> arr2 = new ArrayList<>();
      List<Integer> want = new ArrayList<>();
      
      for (int num : arr1Array) arr1.add(num);
      for (int num : arr2Array) arr2.add(num);
      for (int num : wantArray) want.add(num);
      
      List<Integer> got = solution.solve(arr1, arr2);
      if (!got.equals(want)) {
        throw new RuntimeException(String.format(
            "\nsolve(%s, %s): got: %s, want: %s\n",
            arr1, arr2, got, want));
      }
    }
  }
}
