Given a string, word, consisting of lowercase letters only, return a sorted array with all the letters in word sorted from most frequent to least frequent. If two frequencies are the same, break the tie alphabetically.


Example 1: word = "supercalifragilisticexpialidocious"
Output: ['i', 'a', 'c', 'l', 's', 'e', 'o', 'p', 'r', 'u', 'd', 'f', 'g', 't',
'x']

Example 2: word = "aabbbcccc"
Output: ['c', 'b', 'a']. 'c' appears 4 times, 'b' appears 3 times, and 'a'
appears 2 times.

Example 3: word = "abc"
Output: ['a', 'b', 'c']. All letters appear once, so they are sorted
alphabetically.
Constraints:

The length of word is at most 10^5
word contains only lowercase letters
See Solution
Problem 31.1 - Sorting by Frequency: Solution
Java
We can leverage the frequency map idea to build a map from each letter to its frequency. We can then convert the map to an array of (letter, frequency) tuples and sort the tuples based on the frequencies, breaking ties by the letter.

In particular, we negate the frequencies so larger frequencies appear first. This is a common trick when we want to sort in descending order but the built-in sort is ascending.

Here is the implementation:

class LetterOccurrences {
  public List<Character> solve(String word) {
    Map<Character, Integer> letterToCount = new HashMap<>();
    for (char c : word.toCharArray()) {
      letterToCount.put(c, letterToCount.getOrDefault(c, 0) + 1);
    }

    List<Map.Entry<Character, Integer>> tuples = new ArrayList<>(
        letterToCount.entrySet());
    tuples.sort((a, b) -> {
      if (!a.getValue().equals(b.getValue())) {
        return b.getValue() - a.getValue(); // Sort by frequency descending
      }
      return a.getKey().compareTo(b.getKey()); // Break ties by letter ascending
    });

    List<Character> res = new ArrayList<>();
    for (Map.Entry<Character, Integer> entry : tuples) {
      res.add(entry.getKey());
    }
    return res;
  }
}
Alternatively, since we don't need to output the counts at the end, we can store the unique letters in a list as we encounter them while building the frequency map. Then, we can sort that list directly, using a lambda that looks up the counts in the frequency map and keeps the tie-breaker alphabetical:

class LetterOccurrencesLambda {
  public List<Character> solve(String word) {
    Map<Character, Integer> letterToCount = new HashMap<>();
    List<Character> res = new ArrayList<>();
    for (char c : word.toCharArray()) {
      if (!letterToCount.containsKey(c)) {
        letterToCount.put(c, 0);
        res.add(c);
      }
      letterToCount.put(c, letterToCount.get(c) + 1);
    }

    res.sort((a, b) -> {
      int countA = letterToCount.get(a);
      int countB = letterToCount.get(b);
      if (countA != countB) {
        return Integer.compare(countB, countA);
      }
      return Character.compare(a, b);
    });
    return res;
  }
}
Time & Space Analysis
n: the length of the input string

Time: O(n) - we make one pass through the string to build the frequency map (O(n)), then sort the unique letters. Library sorts use optimal sorting algorithms like quicksort or mergesort under the hood (or common variations of them like Timsort) and take O(n log n) time. Since the number of letters are just the lowercase alphabet, this sort becomes constant time (O(26 log 26)).

Extra space: O(1) - we store at most 26 letters in our frequency map and result array.

def letter_occurrences(word):
  letter_to_count = dict()
  for c in word:
    if c not in letter_to_count:
      letter_to_count[c] = 0
    letter_to_count[c] += 1

  tuples = []
  for letter, count in letter_to_count.items():
    tuples.append((letter, count))
  tuples.sort(key=lambda x: (-x[1], x[0]))
  res = []
  for letter, _ in tuples:
    res.append(letter)
  return res

function letterOccurrences(word) {
  const letterToCount = new Map();
  for (const c of word) {
    letterToCount.set(c, (letterToCount.get(c) || 0) + 1);
  }

  const tuples = [];
  for (const [letter, count] of letterToCount) {
    tuples.push([letter, count]);
  }
  tuples.sort((a, b) => {
    if (a[1] !== b[1]) {
      return b[1] - a[1]; // Sort by frequency descending
    }
    return a[0] < b[0] ? -1 : 1; // Break ties by letter ascending
  });
  const res = [];
  for (const [letter, _] of tuples) {
    res.push(letter);
  }
  return res;
}

function letterOccurrencesLambda(word) {
  const letterToCount = new Map();
  const res = [];
  for (const c of word) {
    if (!letterToCount.has(c)) {
      letterToCount.set(c, 0);
      res.push(c);
    }
    letterToCount.set(c, letterToCount.get(c) + 1);
  }
  res.sort((a, b) => {
    const countA = letterToCount.get(a);
    const countB = letterToCount.get(b);
    if (countA !== countB) return countB - countA;
    return a < b ? -1 : 1;
  });
  return res;
}
