In a mock interview booking system, there is a list of n time slots available to book interviews. We are given:

An array, slots, of length n > 0, where slots[i] is the number of bookings already made for slot i.
An array, bookings, of length k >= 0, where each element represents a bulk booking for a given range. Each element is an array with 3 integers: [l, r, c], where [l, r] is the range of requested slots (both inclusive), and c is the number of clients booked for the entire range. We can assume that 0 <= l <= r < n and c > 0.
A positive integer, cap, representing the maximum number of interviews that can be accommodated at any given slot.
Return the number of slots that are overbooked (i.e., have more bookings than the capacity allows).


Example 1:
slots = [0, 0, 0, 0, 0, 0]
bookings = [[0, 3, 4], [2, 5, 1], [4, 4, 3]]
cap = 5

Output: 0
The number of bookings at each slot is [4, 4, 5, 5, 4, 1].
None of them is over the cap.

Example 2:
slots = [1, 1, 0, 0, 2, 3]
bookings = [[0, 3, 4], [2, 5, 1], [4, 4, 3]]
cap = 4

Output: 5
The number of bookings at each slot is [5, 5, 5, 5, 6, 4].
Constraints:

1 <= slots.length <= 10^5
0 <= slots[i] <= 10^5
0 <= bookings.length <= 10^5
bookings[i].length is 3
0 <= bookings[i][0] <= bookings[i][1] < slots.length
bookings[i][2] > 0
1 <= cap <= 10^6

Problem 43.10 - All Overbooked Slots: Solution
Python
Let's start with the 'indented English' version of the naive solution:

initialize the result array as a copy of the initial slots
for each booking [l, r, c]
  for each index from l to r
    add c to the slot count
count how many slots exceed the capacity
This approach is inefficient because each booking could span the entire array and take O(n) time to process, resulting in a total time complexity of O(n*k), where k is the number of bookings.

A more efficient solution uses the difference array technique to handle range updates efficiently. For each booking [l, r, c], instead of updating every slot in the range directly, we can create two "instructions":

When we reach slot l, increase the booking count by c
When we reach slot r+1, decrease the booking count by c
The key insight is that we can write these instructions directly at the indices where they should be applied. For a booking [l, r, c], we do:

diff[l] += c
diff[r+1] -= c (if r+1 is within bounds)
The array with these "instructions" written directly into it is called a difference array. The crucial property is that the prefix sum of the difference array gives us the cumulative effect of all range updates.

This works because when we add a booking count c at index l, the prefix sum will "carry" this value through all subsequent indices. Then, when we reach r+1, we subtract c to "undo" the effect, ensuring the booking count only applies to the range [l, r].

Our implementation consists of four main steps:

Build the difference array from all bookings
Compute the prefix sums of the difference array to get the total booking counts from bulk bookings
Add the initial slot bookings to get the final booking counts for each slot
Count how many slots exceed the capacity
We can use the (first half of the) range-sum-queries recipe for step 2:

# Initialization
Initialize prefix_sum with the same length as the input array
prefix_sum[0] = arr[0]  # There must be at least one element.
for i from 1 to len(arr) - 1:
  prefix_sum[i] = prefix_sum[i-1] + arr[i]

# Query: sum of subarray [l, r]
if l == 0:
  return prefix_sum[r]
return prefix_sum[r] - prefix_sum[l-1]
Here is the implementation:

def all_overbooked_slots(slots, bookings, cap):
  n = len(slots)
  diff = [0] * n
  for l, r, c in bookings:
    diff[l] += c
    if r + 1 < n:
      diff[r + 1] -= c

  # Recipe 1.
  prefix_sum = [0] * n
  prefix_sum[0] = diff[0]
  for i in range(1, n):
    prefix_sum[i] = prefix_sum[i - 1] + diff[i]

  overbooked_count = 0
  for i in range(n):
    total_bookings = prefix_sum[i] + slots[i]
    if total_bookings > cap:
      overbooked_count += 1
  return overbooked_count

function allOverbookedSlots(slots, bookings, cap) {
  const n = slots.length;
  const diff = new Array(n).fill(0);
  for (const [l, r, c] of bookings) {
    diff[l] += c;
    if (r + 1 < n) {
      diff[r + 1] -= c;
    }
  }

  // Recipe 1.
  const prefixSum = new Array(n).fill(0);
  prefixSum[0] = diff[0];
  for (let i = 1; i < n; i++) {
    prefixSum[i] = prefixSum[i - 1] + diff[i];
  }

  let overbookedCount = 0;
  for (let i = 0; i < n; i++) {
    const totalBookings = prefixSum[i] + slots[i];
    if (totalBookings > cap) {
      overbookedCount++;
    }
  }
  return overbookedCount;
}

class AllOverbookedSlots {
  public int solve(int[] slots, int[][] bookings, int cap) {
    int n = slots.length;
    int[] diff = new int[n];
    for (int[] booking : bookings) {
      int l = booking[0], r = booking[1], c = booking[2];
      diff[l] += c;
      if (r + 1 < n) {
        diff[r + 1] -= c;
      }
    }

    // Recipe 1.
    int[] prefixSum = new int[n];
    prefixSum[0] = diff[0];
    for (int i = 1; i < n; i++) {
      prefixSum[i] = prefixSum[i - 1] + diff[i];
    }

    int overbookedCount = 0;
    for (int i = 0; i < n; i++) {
      int totalBookings = prefixSum[i] + slots[i];
      if (totalBookings > cap) {
        overbookedCount++;
      }
    }
    return overbookedCount;
  }
}
