Given an array of integers, arr, return the first balanced index, if there is any, or -1 otherwise. An index is balanced if the sum of the elements to its left is the same as the sum of the elements to its right.


Example:
arr = [3, 5, -2, 7, 2, 2, 2]
Output: 3
Index 3 is balanced because 3 + 5 + (-2) equals 2 + 2 + 2.
Constraints:

The length of arr is at most 10^5
Each element in arr is an integer at most 10^4
See Solution
Problem 43.4 - Balance Point: Solution
Python
Clearly, this problem is related to the prefix sums technique. You might reasonably consider building two separate arrays to store prefix and postfix sums. However, we don't need to. We just need to check if the sum to the left of each index is the same as the sum to the right, and we can update both of these while iterating through the original array -- no extra array needed!

Here is the implementation:

def balanced_index(arr):
  prefix_sum = 0
  postfix_sum = sum(arr) - arr[0]

  for i in range(len(arr)):
    if prefix_sum == postfix_sum:
      return i
    prefix_sum += arr[i]
    if i + 1 < len(arr):
      postfix_sum -= arr[i+1]
  return -1
Time & Space Analysis
n: the length of the arr array

Time: O(n) - two linear passes through the array

Extra space: O(1) - no prefix sums array needed

function balancedIndex(arr) {
  let prefixSum = 0;
  let postfixSum = arr.reduce((a, b) => a + b, 0) - arr[0];

  for (let i = 0; i < arr.length; i++) {
    if (prefixSum === postfixSum) {
      return i;
    }
    prefixSum += arr[i];
    if (i + 1 < arr.length) {
      postfixSum -= arr[i + 1];
    }
  }
  return -1;
}

class BalancedIndex {
  public int solve(int[] arr) {
    int prefixSum = 0;
    int postfixSum = 0;
    for (int x : arr) {
      postfixSum += x;
    }
    postfixSum -= arr[0];

    for (int i = 0; i < arr.length; i++) {
      if (prefixSum == postfixSum) {
        return i;
      }
      prefixSum += arr[i];
      if (i + 1 < arr.length) {
        postfixSum -= arr[i + 1];
      }
    }
    return -1;
  }
}
