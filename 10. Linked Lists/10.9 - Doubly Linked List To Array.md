Given a non-null node, node, from a doubly linked list, which might or might not be the head, return an array with the values in the list, from head to tail.


Example 1:
head = null <-> 1 <-> 2 <-> 3 <-> 4 <-> null
node = a pointer to the node at index 2

Output: [1, 2, 3, 4]

Example 2:
head = null <-> 1 <-> 2 <-> 3 <-> 4 <-> 5 <-> null
node = a pointer to the node at index 0

Output: [1, 2, 3, 4, 5]
Constraints:

You have to create the Node class with an integer val field and prev and next pointers.
The list can contain up to 10^5 nodes.
See Solution
Problem 34.9 - Doubly Linked List To Array: Solution
Python
We can traverse prev pointers from our given node until we reach the head. Then, we can add each node's value in order into a result array as we traverse the list forward.

Here is the implementation:

class Node:
  def __init__(self, val):
    self.val = val
    self.next = None
    self.prev = None

def convert_to_array(node):
  cur = node
  while cur.prev:
    cur = cur.prev
  res = []
  while cur:
    res.append(cur.val)
    cur = cur.next
  return res
Time & Space Analysis
n: the number of nodes in the doubly linked list

Time: O(n) - we first traverse backwards to find the head of the list, then traverse forwards to collect all values.

Extra space: O(n) - we create an array to store all the values from the linked list.

  let cur = node;

    cur = cur.prev;

  while (cur) {
    res.push(cur.val);
    cur = cur.next;
  }
  return res;
}

class Node {
  int val;
  Node next;
  Node prev;

  Node(int x) {
    val = x;
    next = null;
    prev = null;
  }
}

class ConvertToArray {
  public List<Integer> solve(Node node) {
    Node cur = node;
    while (cur.prev != null) {
      cur = cur.prev;
    }
    List<Integer> res = new ArrayList<>();
    while (cur != null) {
      res.add(cur.val);
      cur = cur.next;
    }
    return res;
  }
}
