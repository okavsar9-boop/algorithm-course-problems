Given the array sales, where sales[i] is the number of sales on the i-th day, find the longest sequence of days alternating between good days and bad days.

A good day is a day with at least 10 sales. A bad day is a day with fewer than 10 sales.


Example 1: sales = [8, 9, 20, 0, 9]
Output: 3. The only good day is day 2, so the subarray [9, 20, 0] alternates
from bad to good to bad.

Example 2: sales = [0, 0, 0]
Output: 1. Every day is bad, so we cannot find any pair of consecutive days
that alternate.

Example 3: sales = [5, 10, 5, 10]
Output: 4. The entire array alternates between bad and good days.
Constraints:

0 <= len(sales) <= 10^5
0 <= sales[i] <= 10^3

Problem 38.7 Longest Alternating Sequence: Solution
JavaScript
We'll approach this problem with a sliding window.

If we find two consecutive days that are both good or both bad, the whole window becomes invalid and we need to reset it. This gives us a simple strategy for when to grow and shrink the window:

We can grow the window when it is (a) empty or (b) the next element does not break the "chain" of alternating days ((sales[r-1] >= 10) != (sales[r] >= 10)).
Otherwise, we reset the window starting from the second of the two consecutive elements of the same type.
We can use the resetting window recipe:

resetting_window(arr):
  initialize:
    - l and r to 0 (empty window)
    - data structures to track window info
    - cur_best to 0
  while we can grow the window (r < len(arr))
    if the window is still valid with one more element
      grow the window (update data structures and increase r)
      update cur_best if needed
    else
      reset window and data structures past the problematic element
  return cur_best
Here is the implementation:

function longestAlternatingSequence(sales) {
  let l = 0,
    r = 0;
  let curMax = 0;
  while (r < sales.length) {
    const canGrow = l === r || sales[r - 1] >= 10 !== sales[r] >= 10;
    if (canGrow) {
      r++;
      curMax = Math.max(curMax, r - l);
    } else {
      l = r;
      r++;
    }
  }
  return curMax;
}
