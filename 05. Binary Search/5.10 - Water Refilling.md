
You have an empty container with a capacity of a gallons of water and another container with a capacity of b gallons. Return how many times you can pour the second container full of water into the first one without overflowing. Assume that a > b.

Constraint: You are not allowed to use the division operation, but you can still divide by powers of two with the right-shift operator, >>. Recall that x >> 1 is the same as x // 2.


Example 1: a = 18, b = 5
Output: 3. After pouring 5 gallons three times, the first container will be at
15, and 5 more gallons would make it overflow.

Example 2: a = 10, b = 2
Output: 5

Example 3: a = 10, b = 3
Output: 3
Constraints:

1 <= b < a <= 10^9
Division operation is not allowed (only right-shift for powers of 2)
See Solution
Problem 29.10 - Water Refilling: Solution
Python
This problem can be solved using a combination of exponential search and binary search. If you're doing problems in the order from the book, you'll have already seen exponential search in the problem: Search In A Huge Array. If this idea is new to you, definitely check that problem out if you'd like more than the brief explanation provided here. You can also read about exponential search on Wikipedia.

The goal is to find the maximum number of times the second container can be poured into the first without exceeding its capacity.

Exponential Search: Start by doubling the number of refills until the total volume exceeds the capacity of the first container. This helps in finding an upper bound for the binary search.

Binary Search: Use binary search between the lower bound (half of the last valid k) and the upper bound found in the exponential search. The binary search helps in efficiently finding the maximum number of refills.

The is_before function checks if a given number of refills is valid by comparing the total volume with the capacity of the first container.

We can use the transition-point recipe:

transition_point_recipe()
  define is_before(val) to return whether val is 'before'
  initialize l and r to the first and last values in the range
  handle edge cases:
    - the range is empty
    - l is 'after'  (the whole range is 'after')
    - r is 'before' (the whole range is 'before')

  while l and r are not next to each other (r - l > 1)
    mid = (l + r) / 2
    if is_before(mid)
      l = mid
    else
      r = mid

  return l (the last 'before'), r (the first 'after'), or something else,
         depending on the problem
Here is the implementation:

def num_refills(a, b):

  # "Can we pour 'num_pours' times?"
  def is_before(num_pours):
    return num_pours * b <= a

  # Exponential search (repeated doubling until we find an upper bound).
  k = 1
  while is_before(k * 2):
    k *= 2

  # Binary search between k and k*2
  l, r = k, k * 2
  while r-l > 1:
    gap = r - l
    half_gap = gap >> 1  # Bit shift instead of division
    mid = l + half_gap
    if is_before(mid):
      l = mid
    else:
      r = mid
  return l
Time & Space Analysis
a: capacity of the first container

b: capacity of the second container

k: the maximum number of refills (the answer)

Time: O(log k) - The exponential search phase takes O(log k) steps to find an upper bound, and then the binary search phase takes another O(log k) steps to find the exact answer. Since k = a / b, this is O(log(a/b)).

Extra space: O(1) - We only use a constant amount of extra space regardless of the input size.

function numRefills(a, b) {
  // "Can we pour 'numPours' times?"
  function isBefore(numPours) {
    return numPours * b <= a;
  }

  // Exponential search (repeated doubling until we find an upper bound).
  let k = 1;
  while (isBefore(k * 2)) {
    k *= 2;
  }

  // Binary search between k and k*2
  let l = k;
  let r = k * 2;
  while (r - l > 1) {
    const gap = r - l;
    const halfGap = gap >> 1; // Bit shift instead of division
    const mid = l + halfGap;
    if (isBefore(mid)) {
      l = mid;
    } else {
      r = mid;
    }
  }
  return l;
}

class NumRefills {
  public int solve(int a, int b) {
    // "Can we pour 'numPours' times?"
    int k = 1;
    while (k * 2 * b <= a) {
      k *= 2;
    }

    int l = k;
    int r = k * 2;
    while (r - l > 1) {
      int gap = r - l;
      int halfGap = gap >> 1; // Bit shift instead of division
      int mid = l + halfGap;
      if (mid * b <= a) {
        l = mid;
      } else {
        r = mid;
      }
    }
    return l;
  }
}
