Given a binary tree, we say a node is aligned if its value is equal to its depth (distance from root). Return the length of the longest path of aligned nodes. A path can start and end at any node.


Example:
                7
               / \
              1   4
             / \   \
            2   8   2
           / \     / \
          4   3   3   3

Output: 3
The aligned nodes are the circled ones:
Depth
  0             7
               / \
  1          (1)   3
             / \   \
  2        (2)  8  (2)
           / \     / \
  3       4  (3) (3) (3)

There are two paths of aligned nodes with maximum length: 1 -> 2 -> 3 on the
left subtree, and 3 -> 2 -> 3 on the right subtree.
Constraints:

The number of nodes is at most 10^5
The height of the tree is at most 500
Each node has a value between 0 and 10^9
See Solution
Problem 35.3 - Aligned Path: Solution
Python
A useful property in problems about finding paths in binary trees is that a path has a single node with minimum depth.

This allows us to use the break down the problem booster in problems about finding paths:

Find the node with minimum depth (closest to the root) in the path.
Construct the path as two descendant chains in the left subtree and the right subtree.
For this problem, how do we characterize the node with minimum depth in the optimal path?

First, it has to be aligned. Among aligned nodes, we want to find one with long aligned descendant chains on both subtrees.

To be precise, we want to maximize the sum of the lengths of the descendant chains.

Now that we know what we want to find, we can think about how.

The first question we should ask for binary tree problems is: "What information do I need to pass through the tree, and in which direction?"

Information directions
![alt text](image-5.png)

For this problem:

We pass the current depth down the tree (a node doesn't know its own depth by itself).
We pass the longest aligned chain starting at each node up the tree.
We track the longest aligned path seen so far using global (non-local) state.
Here is the implementation:

class Node:
  def __init__(self, val, left=None, right=None):
    self.val = val
    self.left = left
    self.right = right

def aligned_path(root):
  res = 0

  def visit(node, depth):
    nonlocal res
    if not node:
      return 0
    left_chain = visit(node.left, depth + 1)
    right_chain = visit(node.right, depth + 1)
    current_chain = 0
    if node.val == depth:
      current_chain = 1 + max(left_chain, right_chain)
      # For each aligned node, try using it as the highest node in the path
      res = max(res, left_chain + right_chain + 1)
    return current_chain

  visit(root, 0)
  return res

function alignedPath(root) {
  let res = 0;

  function visit(node, depth) {
    if (!node) {
      return 0;
    }
    const leftChain = visit(node.left, depth + 1);
    const rightChain = visit(node.right, depth + 1);
    let currentChain = 0;
    if (node.val === depth) {
      currentChain = 1 + Math.max(leftChain, rightChain);
      // For each aligned node, try using it as the highest node in the path
      res = Math.max(res, leftChain + rightChain + 1);
    }
    return currentChain;
  }

  visit(root, 0);
  return res;
}

class AlignedPath {
  private int res = 0;

  private int visit(Node node, int depth) {
    if (node == null) {
      return 0;
    }
    int leftChain = visit(node.left, depth + 1);
    int rightChain = visit(node.right, depth + 1);
    int currentChain = 0;
    if (node.value == depth) {
      currentChain = 1 + Math.max(leftChain, rightChain);
      // For each aligned node, try using it as the highest node in the path
      res = Math.max(res, leftChain + rightChain + 1);
    }
    return currentChain;
  }

  public int solve(Node root) {
    res = 0;
    visit(root, 0);
    return res;
  }
}
